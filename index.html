SahcharAI – गोपनीयता नीति

अंतिम अद्यतन: 5 अप्रैल 2026

SahcharAI (“हम”, “हमारा”) आपकी निजता का पूरा सम्मान करता है। यह गोपनीयता नीति बताती है कि हम कौन-सी जानकारी एकत्र करते हैं, उसका उपयोग कैसे करते हैं, और आपके डेटा को सुरक्षित रखने के लिए हम क्या उपाय करते हैं।

1. हम कौन-सी जानकारी एकत्र करते हैं?

हम केवल निम्नलिखित सीमित जानकारी एकत्र करते हैं:

  • चैट संदेश और इमेज प्रॉम्प्ट: जब आप AI चैट का उपयोग करते हैं, तो आपके संदेश चुने गए AI मोड (DeepSeek/OpenAI/NVIDIA) के API को भेजे जाते हैं। इमेज जनरेशन के लिए आपके द्वारा लिखा गया विवरण (प्रॉम्प्ट) OpenAI DALL-E API को भेजा जाता है।
  • चैट हिस्ट्री: आपकी बातचीत MongoDB में सुरक्षित रखी जाती है ताकि आप पिछली बातचीत देख सकें। आप किसी भी समय अपना डेटा हटाने का अनुरोध कर सकते हैं।
  • अपलोड की गई इमेज: जब आप गैलरी से इमेज चुनते हैं या कैमरा से फोटो लेते हैं, तो इमेज AI विश्लेषण के लिए हमारे सर्वर पर भेजी जाती है। विश्लेषण पूरा होने के बाद इमेज हटा दी जाती है। हम किसी भी इमेज को स्थायी रूप से स्टोर नहीं करते।
  • वॉयस इनपुट: वॉयस कमांड को टेक्स्ट में बदलने के लिए Google Speech API का उपयोग किया जाता है। ऑडियो रिकॉर्डिंग स्टोर नहीं की जाती।
  • गुमनाम तकनीकी लॉग: ऐप के प्रदर्शन को बेहतर बनाने और क्रैश की समस्या सुलझाने के लिए हम गुमनाम तकनीकी डेटा (जैसे डिवाइस मॉडल, Android वर्जन) एकत्र कर सकते हैं।
  • फीडबैक फॉर्म से जानकारी: यदि आप हमारे फीडबैक फॉर्म के माध्यम से सुझाव देते हैं, तो आपके द्वारा दी गई जानकारी (जैसे नाम, ईमेल, रेटिंग) हम तक पहुँचती है।
🔒 हम निम्नलिखित संवेदनशील जानकारी कभी एकत्र नहीं करते:
  • आधार नंबर, पैन कार्ड, या कोई सरकारी पहचान पत्र
  • बैंक खाता, क्रेडिट कार्ड, या भुगतान विवरण
  • पासवर्ड, OTP, या लॉगिन जानकारी
  • लोकेशन, संपर्क सूची

2. जानकारी का उपयोग कैसे किया जाता है?

  • तीन AI मोड: ऐप तीन AI मोड प्रदान करता है – SahcharAI (DeepSeek), SahcharAssistant (OpenAI), SuperSahchar (NVIDIA NIM)। आपके द्वारा चुने गए मोड के अनुसार आपके संदेश संबंधित API को भेजे जाते हैं।
  • इमेज जनरेशन: DALL·E 3 API से चित्र बनाने के लिए आपके प्रॉम्प्ट का उपयोग किया जाता है।
  • वीडियो जनरेशन: आपके प्रॉम्प्ट के आधार पर वीडियो बनाने के लिए RunwayML, Replicate (Zeroscope), या OpenAI Sora API का उपयोग किया जाता है।
  • इमेज विश्लेषण (Upload & Ask): गैलरी या कैमरा से चुनी गई इमेज का विश्लेषण OpenAI GPT-4o-mini Vision API द्वारा किया जाता है।
  • गुमनाम लॉग: इनका उपयोग केवल ऐप की स्थिरता सुधारने, बग ठीक करने और प्रदर्शन बढ़ाने के लिए किया जाता है।

3. परमिशन (Permissions)

SahcharAI निम्नलिखित परमिशन का उपयोग करता है:

  • CAMERA: कैमरा से फोटो लेकर AI विश्लेषण के लिए भेजने हेतु।
  • READ_MEDIA_IMAGES: गैलरी से इमेज चुनकर AI विश्लेषण के लिए भेजने हेतु।
  • RECORD_AUDIO: वॉयस कमांड के लिए (स्पीच रिकग्निशन)।
  • INTERNET: AI API से कनेक्ट करने के लिए।
